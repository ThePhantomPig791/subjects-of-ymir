# Subjects of Ymir

## Adding a Titan:
Please also look at the example pack!!!
1. Create a file named `<titan>.json` in `data/<namespace>/titans/`. This is where properties of the titan, like size and speed, are defined.
2. Create `<titan>.json` in `data/<namespace>/palladium/powers/titan/`. This power should contain a render layer (you can use the generic titan render layer) and an ability for unshifting. Variants are also defined here.
3. Create `skin.png`, `muscle.png`, `skeleton.png`, `hair.png`, `eyes.png`, and `marks.png` in `assets/<namespace>/textures/models/titan/<titan>/<variant>/` for each variant of your titan.
4. Create `skin.geo.json`, `muscle.geo.json`, and `skeleton.geo.json` in `assets/<namespace>/geo/titan/<titan>/<variant>/` for each variant.
5. Create `<variant>.png`, `<variant>_hair.png` and `<variant>_eyes.png` in `assets/<namespace>/textures/icon/titan_face/<titan>/` for each variant.
